## 🇬🇧 English Version

### 📋 Overview
BusinessRadar is a web platform for Micro, Small, and Medium Enterprises (MSMEs).  
It displays upcoming public events on an interactive map within a custom search range, helping businesses anticipate demand and capture opportunities.  

**🎯 Demo:** [Google Slides](https://docs.google.com/presentation/d/1TkGB4P0EvWyFs2KsBtTQNaFSEUQ3saorDcyjx8ihf9U/edit?usp=sharing)

### 🎯 Key Benefits
1. **📦 Inventory** – Stock up ahead of events  
2. **👥 Staffing** – Adjust rosters for peak days  
3. **📢 Marketing** – Target large event audiences  

### 💼 Use Cases
- **🍽️ Restaurant:** Track events within 1km to prepare stock, staff, and promotions.  
- **🎨 Artist:** Get alerts a month ahead for markets within 10km to plan artwork and sales.  

### 🖥️ Interface
- **Left Panel:** Location input, distance slider, filters, top 10 event list (name, date, address, tags, link).  
- **Right Panel:** Map with user location, event pins, zoom & click details.  
- **Top Bar:** Login + Pro upgrade.  

### 🛠️ Tech
- Responsive web frontend  
- Interactive maps with GPS/address detection  
- Public event APIs + relevance ranking  
- Secure login & preferences  

### 💎 Plans
- **🆓 Free:** 10 events/search, standard map, limited radius  
- **⭐ Pro:** Unlimited events, larger radius, advanced filters, priority alerts, analytics, export  

### 🚀 How to Start
1. Open BusinessRadar  
2. Enter location  
3. Set range & filters  
4. View events on map/list  
5. Plan inventory, staff, and promotions

## 🇨🇳 中文版本

### 📋 概述
BusinessRadar是一款为中小微企业打造的智能商机平台。  
它在地图上展示搜索范围内的即将举行的活动，帮助企业提前规划库存、人力和营销。  

**🎯 演示:** [Google Slides](https://docs.google.com/presentation/d/1TkGB4P0EvWyFs2KsBtTQNaFSEUQ3saorDcyjx8ihf9U/edit?usp=sharing)

### 🎯 核心价值
1. **📦 库存** – 提前备货  
2. **👥 人员** – 优化排班  
3. **📢 营销** – 精准触达活动人群  

### 💼 应用场景
- **🍽️ 餐厅:** 关注1公里内活动，合理安排库存、人员和促销。  
- **🎨 艺术家:** 提前1个月获知10公里内市集，联系主办方并准备作品。  

### 🖥️ 界面
- **左侧:** 地址输入、距离选择、分类筛选、活动列表（名称、时间、地址、标签、链接）。  
- **右侧:** 地图标记用户与活动，可缩放和点击查看详情。  
- **顶部:** 登录 + Pro升级。  

### 🛠️ 技术
- 响应式前端  
- GPS/地址定位 + 交互地图  
- 公共活动API + 相关性排序  
- 用户登录与偏好存储  

### 💎 版本
- **🆓 免费版:** 每次最多10个活动，标准地图，有限半径  
- **⭐ Pro版:** 无限结果，扩展半径，高级筛选，优先通知，分析导出  

### 🚀 快速开始
1. 打开BusinessRadar  
2. 输入地址  
3. 设置范围和筛选条件  
4. 浏览地图和列表  
5. 提前安排库存、人力和营销
